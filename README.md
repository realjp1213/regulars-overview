# Regulars

A web app that matches people into small friendship groups of three or four who meet weekly. Starting in Newcastle. [the-regulars.app](https://the-regulars.app)

Side project, built end to end with Claude Code. The repo is private while it launches. Happy to open it or walk through it on request.

---

## The idea

Making friends as an adult is hard. Apps like Timeleft put strangers in a restaurant once. Regulars does something smaller and more lasting: a short questionnaire, a match into a group of three or four people of the same gender in the same city, and a first meetup at a pub or café. If it goes well, the same group meets again. A "season" rather than a one-off.

## What it does

- A free questionnaire on personality and interests.
- A matching engine that builds groups, based on the same approach as SuccessWay's.
- A list of shared topics for each group, so the first meetup is not awkward.
- A small upfront payment (£7.99 founding price) before matching, explained clearly before the quiz starts.

## How it is built

- **Web app:** custom site and questionnaire built with Claude Code
- **Database:** Supabase
- **Matching:** Python
- **Payments:** Stripe

## Decisions

- Web app first, not native. Faster to ship and test the idea.
- Pay upfront, not after the first meet. Keeps groups together instead of swapping numbers and leaving.
- Plain UK tone in all copy. Nothing corny.
- My name, photo and LinkedIn are on the site, so there is a real person behind it.
